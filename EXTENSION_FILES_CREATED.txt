🚀 QUICK START (3 STEPS)
═════════════════════════════════════════════════════════════════════════════

STEP 1: Start Backend Server
───────────────────────────
  cd server
  npm install
  npm start
  # Server runs on http://localhost:5000

STEP 2: Configure Extension API URL
────────────────────────────────────
  Open: extension/popup.js
  Change line 1:
    const API_BASE = 'http://localhost:5000/api';  ← THIS LINE
  
  For production, change to your domain:
    const API_BASE = 'https://your-domain.com/api';

STEP 3: Load Extension in Chrome
──────────────────────────────────
  1. Open: chrome://extensions/
  2. Enable: Developer Mode (top right toggle)
  3. Click: "Load unpacked"
  4. Select: The extension/ folder from this repo
  5. Done! Extension now appears in your toolbar 🎉

🔐 SECURITY NOTES
═════════════════════════════════════════════════════════════════════════════

✅ Passwords are encrypted end-to-end
   - Server cannot read them
   - Only your device can decrypt

✅ Extension uses JWT tokens
   - Token expires after 30 days
   - Stored securely in browser

✅ No plain text logging
   - Passwords never appear in console
   - Only sent to trusted API endpoint

✅ CORS restricted
   - Only your domain can access API
   - Extension must be added to allowed origins

🐛 TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

❌ "Extension won't load"
   ✓ Check: chrome://extensions/
   ✓ Enable Developer Mode toggle
   ✓ Load unpacked → select extension/ folder

❌ "Login fails"
   ✓ Start server: npm start in server/
   ✓ Check: http://localhost:5000/health
   ✓ Verify API_BASE URL in extension/popup.js

❌ "Autofill not working"
   ✓ Make sure you're on a login page with <input> fields
   ✓ Try on: https://httpbin.org/forms/post
   ✓ Check browser console (right-click → Inspect)

❌ "CORS error"
   ✓ Add extension ID to server/app.js allowedOrigins
   ✓ Get ID from chrome://extensions/
   ✓ Add: 'chrome-extension://YOUR_ID'
